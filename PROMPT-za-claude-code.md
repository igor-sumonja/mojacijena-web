# Prvi zadatak za Claude Code (kopiraj u terminal nakon `claude` u ovom folderu)

Pročitaj CLAUDE.md i README.md. Zatim:

1. Pokreni `npm install` i `npm run build`; potvrdi da build prolazi.
2. Dodaj `@astrojs/sitemap` u astro.config.mjs (site je već postavljen) i provjeri da `/sitemap-index.xml` postoji u buildu.
3. Zamijeni placeholdere `[ADRESA]`, `[TELEFON]`, `[E-MAIL]` u `src/pages/index.astro` i `src/pages/kontakt.astro` ovim podacima: [UPIŠI].
4. U `src/pages/knjigovodje.astro` zamijeni `[IZNOS]` s: [UPIŠI].
5. Inicijaliziraj git, napravi prvi commit i ispiši mi točne korake za Coolify (Dockerfile build pack, port 4321, env varijable iz .env.example).

Ne mijenjaj tekstove na stranicama izvan onoga što je gore navedeno. Nakon svake promjene pokreni `npm run build`.
